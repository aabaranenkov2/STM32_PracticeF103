# Проект: Nextion + DS3231 для STM32F103C8T6

## 📋 Описание

Проект для отображения времени и температуры на дисплее Nextion NX4832T035_011 с возможностью установки времени через интерфейс.

**Функции:**
- ✅ Отображение времени (HH:MM:SS) и даты (DD.MM.YYYY)
- ✅ Отображение температуры с DS3231
- ✅ Установка времени через интерфейс Nextion
- ✅ Обновление данных каждые 500 мс

---

## 🔌 Подключение

### Nextion NX4832T035_011:
- **VCC** → 5V (через преобразователь уровней)
- **GND** → GND
- **RX** → PA2 (USART2_TX) через преобразователь 3.3V→5V
- **TX** → PA3 (USART2_RX) через преобразователь 5V→3.3V

### DS3231SN:
- **VCC** → 3.3V
- **GND** → GND
- **SDA** → PB7 (I2C1_SDA)
- **SCL** → PB6 (I2C1_SCL)

**⚠️ ВАЖНО:** Для Nextion нужен преобразователь уровней (3.3V ↔ 5V)!

Подробнее: [CONNECTION_GUIDE.md](CONNECTION_GUIDE.md)

## 🎨 Создание интерфейса Nextion

1. **Скачайте Nextion Editor:**
   - https://nextion.tech/nextion-editor/

2. **Создайте проект:**
   - Модель: NX4832T035_011
   - Разрешение: 480×320

3. **Создайте страницы:**
   - Страница 0: Главная (время, дата, температура, кнопка Settings)
   - Страница 1: Установка времени (часы, минуты, секунды, кнопки +/-)

4. **Загрузите интерфейс:**
   - Скомпилируйте проект (.tft файл)
   - Скопируйте на microSD и вставьте в дисплей

Подробнее: [NEXTION_INTERFACE.md](NEXTION_INTERFACE.md)

## 🎯 Использование

### Главная страница (Page 0):
- Отображает текущее время и дату

## ⚠️ Важные замечания

1. **Уровни напряжения:**
   - Nextion работает на 5V, STM32 на 3.3V
   - Обязательно используйте преобразователь уровней!

2. **I2C подтяжка:**
   - DS3231 требует подтягивающие резисторы (4.7kΩ) на SDA и SCL

3. **ID компонентов:**
   - В Nextion Editor установите правильные ID компонентов (0-7)
   - ID используются в коде для обработки событий

4. **Имена компонентов:**
   - Имена компонентов должны точно совпадать с кодом
   - См. NEXTION_INTERFACE.md для списка имен

## 🔍 Отладка

### Проблема: Дисплей не показывает данные
- Проверьте подключение UART
- Проверьте уровни напряжения
- Проверьте, что интерфейс загружен на дисплей

### Проблема: Время не обновляется
- Проверьте подключение I2C (DS3231)
- Проверьте подтягивающие резисторы
- LED мигает при ошибке инициализации DS3231

### Проблема: Кнопки не работают
- Проверьте ID компонентов в Nextion Editor
- Проверьте, что события касаний включены
- Проверьте прием данных от UART
