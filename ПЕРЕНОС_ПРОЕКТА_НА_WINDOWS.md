# Быстрый перенос LotSensor на Windows

Есть два разных варианта переноса:

- для обычной работы с прибором нужен только установщик;
- для продолжения разработки нужен весь проект из Git.

## Вариант 1. Только работа с прибором

Это самый быстрый вариант.

1. На Linux найдите файл:

   ```text
   dist/LotSensorSetup-v1.0.5.exe
   ```

2. Скопируйте этот файл на флешку, сетевой диск или в облачную папку.
3. Перенесите файл на компьютер с Windows 10/11 x64.
4. Запустите `LotSensorSetup-v1.0.5.exe`.
5. Если SmartScreen покажет предупреждение, выберите:

   ```text
   Подробнее → Выполнить в любом случае
   ```

6. После установки подключите USB–RS485.
7. Проверьте в диспетчере устройств наличие COM-порта.
8. Запустите ярлык **Лотовый датчик** на рабочем столе.
9. Дождитесь открытия страницы и появления связи с контроллером.

Для обычной эксплуатации не нужны Python, PlatformIO, Cursor и исходники.

## Вариант 2. Перенос проекта для разработки через Git

Этот способ предпочтительнее копирования всей Linux-папки: временные файлы
сборки и Linux-настройки не переносятся.

### 1. Установите программы

На Windows установите:

- Git for Windows;
- Cursor или Visual Studio Code;
- расширение PlatformIO IDE;
- драйвер ST-Link;
- драйвер USB–RS485, например CH340;
- при необходимости STM32CubeProgrammer.

### 2. Клонируйте проект

Откройте PowerShell и выполните:

```powershell
cd $HOME\Documents
git clone https://github.com/aabaranenkov2/STM32_PracticeF103.git
cd STM32_PracticeF103
git status
```

Ожидаемый результат `git status` — рабочая папка без изменений.

### 3. Откройте проект

В Cursor:

```text
File → Open Folder
```

Выберите:

```text
C:\Users\<имя>\Documents\STM32_PracticeF103
```

Если в проекте имеется файл `.code-workspace`, можно открыть его через:

```text
File → Open Workspace from File
```

### 4. Дождитесь настройки PlatformIO

При первом открытии PlatformIO скачает компилятор и библиотеки. Для проверки
откройте терминал Cursor:

```powershell
pio run -e lot_sensor_f103c8_clone
```

### 5. Прошивка контроллера

Подключите ST-Link и выполните:

```powershell
pio run -e lot_sensor_f103c8_clone -t upload
```

После прошивки отключите ST-Link, если он больше не нужен, и подключите
USB–RS485.

### 6. Запуск веб-программы из исходников

Для разработки установите Python 3.12 x64. Затем:

```powershell
py -m pip install -r web\requirements.txt
py web\server.py
```

Откройте:

```text
http://127.0.0.1:8765/
```

Если нужна только работа с прибором, используйте установленный
`LotSensor.exe`, а не запуск из Python.

## Вариант 3. Копирование всей папки вручную

Можно скопировать всю папку проекта на внешний носитель, но перед переносом
необязательно копировать тяжёлые временные каталоги:

```text
.pio
.windows-build
build
dist
отчеты
__pycache__
```

Исключение: из `dist` отдельно скопируйте
`LotSensorSetup-v1.0.5.exe`, если он нужен для установки.

На Windows вставьте проект, например в:

```text
C:\Users\<имя>\Documents\STM32_PracticeF103
```

После копирования откройте папку в Cursor и дождитесь, пока PlatformIO заново
создаст `.pio`.

Не помещайте проект в слишком длинный путь и по возможности избегайте папок,
которые постоянно синхронизируются OneDrive: это иногда мешает компилятору и
блокирует временные файлы.

## Синхронизация дальнейших изменений

Перед началом работы на Windows:

```powershell
git pull origin main
```

После завершения и проверки:

```powershell
git status
git add <изменённые файлы>
git commit -m "Описание изменения"
git push origin main
```

На Linux перед продолжением:

```bash
git pull origin main
```

Не редактируйте одновременно одни и те же файлы на Linux и Windows до
синхронизации — это создаёт конфликты.

## Что хранится отдельно от Git

В Git не отправляются:

- результаты сборки `.pio`, `build`, `dist`;
- файлы отчётов;
- журналы;
- временные файлы;
- Windows/Wine-окружение сборки.

Поэтому установщик нужно переносить отдельно. Исходники и документация
переносятся через Git.

Рабочие отчёты Windows находятся в:

```text
C:\Users\<имя>\Documents\Лотовый датчик\отчеты
```

Заводской профиль Windows находится в:

```text
%LOCALAPPDATA%\LotSensor\factory_defaults.json
```

При переносе на другой компьютер сначала используйте профиль из установщика.
Если пользовательская копия профиля была изменена вручную и эти изменения
нужны, отдельно перенесите указанный JSON-файл.

## Контроль после переноса

1. Версия страницы — 1.0.5.
2. `/api/version` отвечает `{"version": "1.0.5"}`.
3. COM-порт найден.
4. Вверху страницы отображается связь.
5. Состояние контроллера — **Готов**.
6. Датчик грунта правильно отображается встроенным LED.
7. Внешний запрет не активен.
8. Выполняется парковка.
9. Выполняется один контрольный замер.
10. В папке отчётов появляется запись.
