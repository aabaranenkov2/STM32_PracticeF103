# 📝 Создание и загрузка TFT файла для Nextion дисплея

## 🎯 Что такое TFT файл?

**TFT файл** - это скомпилированный файл прошивки для дисплея Nextion, который содержит:
- Интерфейс (страницы, компоненты, изображения)
- Логику работы компонентов
- Настройки дисплея

**Формат:** `.tft` (Nextion Firmware File)

---

## 📋 Пошаговая инструкция

### Шаг 1: Установка Nextion Editor

1. **Скачайте Nextion Editor:**
   - Официальный сайт: https://nextion.tech/nextion-editor/
   - Или: https://nextion.tech/downloads/
   - Версия: последняя стабильная (обычно 1.65.x или новее)

2. **Установка:**
   - **Windows:** Запустите `.exe` установщик
   - **Linux:** Распакуйте `.tar.gz` архив
   - **Mac:** Установите `.dmg` образ

3. **Запустите Nextion Editor**

---

### Шаг 2: Создание проекта

1. **Создайте новый проект:**
   ```
   File → New → New Project
   ```

2. **Выберите модель дисплея:**
   - В списке найдите: **NX4832T035_011**
   - Или выберите: **NX4832T035** (3.5" 480×320)
   - Нажмите **OK**

3. **Сохраните проект:**
   ```
   File → Save As...
   ```
   - Имя файла: `fitness_clock.HMI` (или любое другое)
   - Расширение должно быть `.HMI` (Nextion Project File)

---

### Шаг 3: Создание интерфейса

#### 3.1. Создание Страницы 0 (Главная)

1. **Добавьте компоненты:**
   - Нажмите на панели инструментов нужный компонент
   - Или: `Toolbox → Components → Text/Button/etc.`

2. **Компоненты для главной страницы:**
   ```
   Text (t_time)     - для времени
   Text (t_date)      - для даты
   Text (t_temp)      - для температуры
   Button (b0)        - кнопка Settings
   ```

3. **Настройка компонента Text (t_time):**
   - Двойной клик на компоненте
   - **Object Name:** `t_time`
   - **Size:** Width=200, Height=50
   - **Position:** X=140, Y=80
   - **Font:** Выберите большой шрифт (например, 24pt)
   - **Text:** `00:00:00` (начальное значение)
   - **Font Color:** Белый (255, 255, 255)
   - **Background Color:** Темно-синий (0, 0, 128)

4. **Настройка компонента Text (t_date):**
   - **Object Name:** `t_date`
   - **Size:** Width=150, Height=30
   - **Position:** X=165, Y=140
   - **Text:** `01.01.2024`
   - **Font Color:** Светло-серый (192, 192, 192)

5. **Настройка компонента Text (t_temp):**
   - **Object Name:** `t_temp`
   - **Size:** Width=120, Height=40
   - **Position:** X=180, Y=200
   - **Text:** `00.00°C`
   - **Font Color:** Желтый (255, 255, 0)

6. **Настройка Button (b0):**
   - **Object Name:** `b0`
   - **Size:** Width=100, Height=40
   - **Position:** X=190, Y=260
   - **Text:** `Settings`
   - **Font Color:** Белый
   - **Background Color:** Синий (0, 0, 255)
   - **Touch Event:** Включить (для обработки в коде)

#### 3.2. Создание Страницы 1 (Установка времени)

1. **Добавьте новую страницу:**
   ```
   Pages → Add Page
   ```
   - Или: Правый клик на Pages → Add Page

2. **Переключитесь на страницу 1:**
   - Двойной клик на "Page 1" в списке страниц

3. **Добавьте компоненты:**
   - Тексты для меток (Hour, Minute, Second)
   - Тексты для значений (t_hour, t_minute, t_second)
   - Кнопки +/- для каждого значения
   - Кнопки Save и Cancel

4. **Настройка компонентов:**
   - См. подробное описание в `NEXTION_INTERFACE.md`

### Шаг 4: Компиляция проекта

1. **Проверьте проект:**
   ```
   File → Build → Check
   ```
   - Убедитесь, что нет ошибок

2. **Скомпилируйте проект:**
   ```
   File → Build → Compile
   ```
   - Или нажмите кнопку **Compile** на панели инструментов

3. **Результат компиляции:**
   - В папке с проектом появится файл `fitness_clock.tft`
   - Размер файла: обычно 100-500 KB (зависит от количества компонентов и изображений)

4. **Проверьте файл:**
   - Убедитесь, что файл `.tft` создан
   - Запомните путь к файлу

### Шаг 5: Подготовка microSD карты

#### 5.1. Требования к microSD:

- **Формат:** FAT32 (обязательно!)
- **Размер:** от 1 MB до 32 GB (рекомендуется 1-8 GB)
- **Класс:** Class 4 или выше (Class 10 рекомендуется)
- **Файловая система:** FAT32 (не exFAT, не NTFS!)

#### 5.2. Форматирование microSD:

**В Linux:**
```bash
# 1. Найдите устройство microSD
lsblk
# Пример вывода: /dev/sdb1

# 2. Размонтируйте (если смонтировано)
sudo umount /dev/sdb1

# 3. Отформатируйте в FAT32
sudo mkfs.vfat -F 32 /dev/sdb1
# Или:
sudo mkfs.fat -F 32 /dev/sdb1
```

**В Windows:**
1. Вставьте microSD в кардридер
2. Правый клик на диске → **Format**
3. **File system:** FAT32
4. **Allocation unit size:** Default
5. Нажмите **Start**

**В Mac:**
1. Откройте **Disk Utility**
2. Выберите microSD
3. **Erase** → **Format:** MS-DOS (FAT32)

### Шаг 6: Копирование TFT файла на microSD

#### 6.1. Важные правила:

1. **Имя файла ДОЛЖНО быть:** `update.tft`
   - ❌ НЕ `fitness_clock.tft`
   - ❌ НЕ `my_project.tft`
   - ✅ ТОЛЬКО `update.tft`

2. **Файл должен быть в корне microSD:**
   ```
   microSD/
   └── update.tft    ← ТОЛЬКО этот файл!
   ```

3. **НЕ создавайте папки:**
   - ❌ `microSD/firmware/update.tft` - НЕ РАБОТАЕТ!
   - ✅ `microSD/update.tft` - РАБОТАЕТ!

#### 6.2. Копирование:

**В Linux:**
```bash
# 1. Смонтируйте microSD (если не смонтирована автоматически)
sudo mount /dev/sdb1 /mnt

# 2. Скопируйте файл с переименованием
cp /path/to/fitness_clock.tft /mnt/update.tft

# 3. Проверьте
ls -lh /mnt/update.tft

# 4. Размонтируйте
sudo umount /mnt
```

**В Windows:**
1. Откройте microSD в проводнике
2. Скопируйте `fitness_clock.tft`
3. Вставьте в корень microSD
4. Переименуйте в `update.tft`

**В Mac:**
```bash
# В терминале:
cp /path/to/fitness_clock.tft /Volumes/MICROSD/update.tft
```

#### 6.3. Проверка:

```bash
# Убедитесь, что файл существует и имеет правильное имя
ls -lh /mnt/update.tft
# Должен показать: update.tft

# Проверьте размер (должен быть > 0)
du -h /mnt/update.tft
```

### Шаг 7: Загрузка на дисплей Nextion

#### 7.1. Подготовка:

1. **Отключите питание дисплея** (если подключен)
2. **Вставьте microSD карту** в слот дисплея
3. **Проверьте подключение:**
   - VCC → 5V
   - GND → GND
   - (UART пока не нужен)

#### 7.2. Процесс загрузки:

1. **Подайте питание на дисплей:**
   - Подключите 5V к VCC
   - Подключите GND к GND

2. **Дисплей автоматически:**
   - Обнаружит файл `update.tft` на microSD
   - Начнет загрузку прошивки
   - Покажет индикатор загрузки (если есть)

3. **Признаки загрузки:**
   - Экран может мигать
   - Может показаться индикатор прогресса
   - Время загрузки: 10-60 секунд (зависит от размера файла)

4. **После загрузки:**
   - Дисплей перезагрузится
   - Покажет новый интерфейс
   - Экран должен работать

#### 7.3. Проверка результата:

1. **Убедитесь, что интерфейс загружен:**
   - Должны отображаться ваши компоненты
   - Текст должен быть виден
   - Кнопки должны реагировать на касания

2. **Если загрузка не удалась:**
   - См. раздел "Устранение проблем" ниже

## 🔧 Альтернативный способ: Загрузка через UART

Если microSD не работает, можно загрузить через UART:

### Шаг 1: Подключение

```
Nextion          USB-UART адаптер
─────────────────────────────────
VCC  →  5V
GND  →  GND
TX   →  RX (адаптера)
RX   →  TX (адаптера)
```

### Шаг 2: Загрузка через Nextion Editor

1. **Подключите дисплей к компьютеру** через USB-UART
2. **Откройте проект** в Nextion Editor
3. **Выберите COM порт:**
   ```
   Tools → Serial Port → Выберите порт
   ```
4. **Загрузите прошивку:**
   ```
   File → Build → Upload
   ```
   - Или кнопка **Upload** на панели инструментов

5. **Дождитесь завершения:**
   - Прогресс показывается в окне
   - Время: 30-120 секунд

## ⚠️ Устранение проблем

### Проблема 1: Дисплей не обновляется

**Симптомы:**
- Дисплей не реагирует на microSD
- Экран остается пустым или показывает старый интерфейс

**Решения:**
1. **Проверьте имя файла:**
   - Должно быть точно `update.tft` (не `Update.tft`, не `UPDATE.TFT`)
   - Регистр важен!

2. **Проверьте формат microSD:**
   ```bash
   # В Linux:
   sudo file -s /dev/sdb1
   # Должно показать: FAT32
   
   # Если не FAT32, отформатируйте:
   sudo mkfs.vfat -F 32 /dev/sdb1
   ```

3. **Проверьте расположение файла:**
   - Файл должен быть в корне microSD
   - Не в папках!

4. **Проверьте размер файла:**
   - Файл должен быть > 0 байт
   - Обычно 100-500 KB

5. **Попробуйте другую microSD:**
   - Некоторые карты несовместимы
   - Используйте карту Class 4-10

6. **Проверьте питание:**
   - Должно быть стабильное 5V
   - Ток: минимум 200mA

### Проблема 2: Ошибка компиляции

**Симптомы:**
- Nextion Editor показывает ошибки при компиляции
- Файл `.tft` не создается

**Решения:**
1. **Проверьте модель дисплея:**
   - Должна совпадать с вашей моделью (NX4832T035_011)

2. **Проверьте компоненты:**
   - Все компоненты должны иметь уникальные имена
   - Имена должны начинаться с буквы

3. **Проверьте размеры:**
   - Компоненты не должны выходить за границы экрана
   - Разрешение: 480×320 для NX4832T035_011

4. **Очистите проект:**
   ```
   File → Build → Clean
   ```
   Затем скомпилируйте снова

### Проблема 3: Интерфейс не работает после загрузки

**Симптомы:**
- Дисплей показывает интерфейс, но не реагирует
- Компоненты не обновляются из кода

**Решения:**
1. **Проверьте имена компонентов:**
   - В коде должны использоваться те же имена, что в проекте
   - Регистр важен! `t_time` ≠ `T_TIME`

2. **Проверьте UART:**
   - Скорость должна совпадать (9600 или 115200)
   - TX/RX должны быть правильно подключены

3. **Проверьте команды:**
   - Команды должны заканчиваться `0xFF 0xFF 0xFF`
   - См. документацию драйвера

## 💡 Полезные советы

1. **Резервное копирование:**
   - Сохраняйте `.HMI` файлы проектов
   - Храните рабочие версии `.tft` файлов

2. **Версионирование:**
   - Используйте имена: `update_v1.tft`, `update_v2.tft`
   - Перед загрузкой переименовывайте в `update.tft`

3. **Тестирование:**
   - Сначала создайте простой интерфейс (одна страница, один текст)
   - Убедитесь, что загрузка работает
   - Затем добавляйте сложность

4. **Оптимизация:**
   - Удаляйте неиспользуемые компоненты
   - Используйте сжатие изображений
   - Это уменьшит размер `.tft` файла
