# Проверка лотового датчика

## Запуск интерфейса

```bash
python3 -m pip install -r web/requirements.txt
python3 web/server.py --serial /dev/ttyUSB0
```

Открыть `http://127.0.0.1:8765`. Для проверки страницы без контроллера:

```bash
python3 web/server.py --simulate
```

## Прошивка

Для подключённого C8-клона:

```bash
pio run -e lot_sensor_f103c8_clone -t upload
```

Для C6:

```bash
pio run -e lot_sensor_f103c6 -t upload
```

Перед прошивкой C6 необходимо подтвердить обычный или clone SWD TAP ID.

## Уже проверено

- Сборка C6: см. вывод `pio run -e lot_sensor_f103c6` (лимит Flash 31 744).
- Сборка C8: 19 092 байт Flash из 64 512 (~29,6 %), 1 188 байт RAM из
  20 480 (~5,8 %) — `pio run -e lot_sensor_f103c8`, октябрь 2026.
- Прошивка подключённого C8-клона через ST-Link V2.
- Обмен запрос/ответ по USB–RS-485, CRC16, status/config, AUTO и STOP.
- Запись конфигурации в последнюю страницу Flash, сброс и чтение после
  перезапуска.
- Потоковый парсер при фрагментации, мусоре и неверном CRC.
- HTTP API и HTML в режиме симулятора.

Последняя страница Flash исключена из допустимого размера production-сборки:
1 КБ используется только для конфигурации. Диагностические прошивки её
использовать не должны одновременно с рабочими настройками.

## Стенд без двигателя

1. Не подключать 24 В. Проверить мультиметром отсутствие более 3,3 В на
   PA0–PA4, PA10, PB4, PB5 и PB14.
2. Поочерёдно замыкать PA0–PA4 на GND. Проверить битовую маску кнопок и
   команды страницы.
3. Подать на `Enc_FA_White = PB4` и `Enc_FB_Green = PB5` квадратурный
   сигнал 0–3,3 В. Проверить знак и число импульсов энкодера.
   Для YT06 600 PPR и TIM3 в режиме квадратуры ×4 ожидается 2400 отсчётов
   на оборот. При диаметре вала 10 мм длина окружности равна 31,4159 мм,
   поэтому один отсчёт соответствует 0,01309 мм, а 1 мм — 76,394 отсчёта.
4. Подать на `Mot_FG_Yellow = PB14` импульсы 0–3,3 В. Проверить счётчик
   `Mot_FG_Yellow`. Для 9 импульсов на оборот двигателя, редуктора 18,8:1
   и барабана диаметром 40 мм один импульс соответствует примерно 0,743 мм.
5. Осциллографом проверить `Mot_PWM_Blue = PA8`: 1 кГц, duty соответствует
   показанию `Mot_PWM_Blue`. Проверить направление через
   `Mot_DIR_White = PB15`.
6. При отключении USB–RS-485 контроллер продолжает автономный автомат, но
   страница должна заблокировать команды.

## Стенд с двигателем

1. Проверить аппаратный STOP до подключения груза.
2. Подключить согласующие каскады по `HARDWARE_WIRING.md`, ограничить ток
   источника и снять нить с барабана.
3. Кратковременно проверить направления «Вверх» и «Вниз». Если направление
   обратное — изменить силовое подключение/полярность DIR до работы с грузом.
4. Проверить `Mot_FG_Yellow` на малом `Mot_PWM_Blue` и остановку по
   отпусканию экранной/физической кнопки.
5. Проверить парковку сначала рукой на имитаторе упора. Убедиться, что PWM
   снижен. После остановки `Mot_FG_Yellow` контроллер должен отключить
   `Mot_PWM_Blue`, выдержать
   паузу отпускания защиты, кратко пойти вниз и снова вернуться к упору.
6. Имитировать зажатие нити: `Mot_FG_Yellow` должен считать, а
   `Enc_FA_White/Enc_FB_Green` оставаться неподвижными. Ожидается ошибка
   «Груз зажат», отключение `Mot_PWM_Blue` и запрет новых движений до
   устранения причины и сброса ошибки.
7. Только после этого установить лёгкий груз, откалибровать импульсы/мм и
   проверить посадку на твёрдую площадку.
8. Провести не менее 20 циклов. Записать путь вниз/вверх, разброс парковки,
   время цикла и все ошибки; затем подобрать таймауты и допустимое
   расхождение.

Силовые испытания без согласования уровней, аппаратного STOP и ограничения
тока запрещены.

## Автоматический цикл измерения

1. STM32 проверяет парковку: подъём до остановки `Mot_FG_Yellow`, ожидание
   защиты, короткий тест вниз и возврат на упор.
2. Груз движется вниз с `run_pwm`. Первые `contact_ignore_ms` (штатно
   1000 мс) контроль контакта отключён; в это время контроллер запоминает
   максимальную скорость Enc.
3. После задержки контакт фиксируется, когда текущая скорость Enc становится
   не выше `contact_speed_percent` от максимальной (штатно 80%).
   Дополнительной выдержки на грунте нет. Остановка `Mot_FG_Yellow` раньше
   контакта — ошибка.
4. STM32 сохраняет расстояние и сразу меняет направление на подъём.
5. Когда остаётся `slowdown_remaining_percent` пути, PWM делится на
   `slowdown_divisor_tenths / 10`. Физический PWM ограничен снизу 45%.
6. Одновременная остановка обоих энкодеров означает парковку. STM32
   сравнивает путь вниз/вверх в миллиметрах; расхождение до 100 мм
   включительно считается допустимым. Затем результат сохраняется,
   счётчики обнуляются и контроллер переходит в «Готов». Проверка парковки
   выполняется перед каждым следующим автоматическим измерением.

Все расчёты расстояния, скорости и переходы состояний выполняет STM32.
HTML только передаёт команды/настройки и отображает телеметрию.
