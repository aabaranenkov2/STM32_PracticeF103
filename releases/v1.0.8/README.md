# LotSensor 1.0.8

Проверенный выпуск после длительного теста автоматических измерений:

- исправлен запуск автоматического спуска после верхнего упора;
- добавлены повторные попытки запуска при отсутствии импульсов Mot_FG;
- добавлено безопасное отключение повторной парковки;
- поле задания циклов работает как обратный счётчик;
- снижена нагрузка на RS-485 и добавлена минутная сводка сбоев;
- время журнала отображается в местном часовом поясе.

Файлы:

- `LotSensor-f103c8-v1.0.8.bin` — прошивка STM32;
- `LotSensor-f103c8-v1.0.8.bin.sha256` — контрольная сумма;
- `LotSensorSetup-v1.0.8.exe.sha256` — контрольная сумма установщика;
- `settings.json` — снимок рабочих настроек контроллера и бункера.

Автоматическое копирование выпуска на флешку:

```bash
./copy_release_to_flash.sh "/media/$USER/ИМЯ_ФЛЕШКИ"
```

В заводском профиле контроль расхождения Enc/Mot_FG отключён. В сохранённом
снимке текущего контроллера он включён: `mismatch_mm = 100`,
`error_measurement_limit = 2`.
