## 📋 Проверка проекта

### Если проект уже открыт:

1. **Посмотрите на левую панель:**
   - Должны быть страницы (Pages)
   - Должны быть компоненты (Components)

2. **Проверьте модель дисплея:**
   - Внизу окна должно быть указано: `NX4832T035_011` или `NX4832T035`
   - Или в меню: `File → Project Settings`

3. **Если проект пустой:**
   - Не будет страниц
   - Не будет компонентов
   - Экран будет пустым

## 🎨 Создание интерфейса

### Страница 0: Главная (отображение времени и температуры)

#### 1. Добавить компонент Text для времени:

1. **На панели инструментов:**
   - Найдите иконку **Text** (буква "T")
   - Или: `Toolbox → Components → Text`

2. **Кликните на экране** (примерно в центре)

3. **Настройте компонент:**
   - **Object Name:** `t_time`
   - **Size:** Width=200, Height=50
   - **Position:** X=140, Y=80
   - **Font:** Выберите большой шрифт (24pt или больше)
   - **Text:** `00:00:00` (начальное значение)
   - **Font Color:** Белый (255, 255, 255)
   - **Background Color:** Темно-синий (0, 0, 128)

#### 2. Добавить компонент Text для даты:

1. **Добавьте еще один Text компонент**

2. **Настройте:**
   - **Object Name:** `t_date`
   - **Size:** Width=150, Height=30
   - **Position:** X=165, Y=140
   - **Text:** `01.01.2024`
   - **Font Color:** Светло-серый (192, 192, 192)

#### 3. Добавить компонент Text для температуры:

1. **Добавьте еще один Text компонент**

2. **Настройте:**
   - **Object Name:** `t_temp`
   - **Size:** Width=120, Height=40
   - **Position:** X=180, Y=200
   - **Text:** `00.00°C`
   - **Font Color:** Желтый (255, 255, 0)
   - **Font:** Средний, жирный

#### 4. Добавить кнопку Settings:

1. **На панели инструментов:**
   - Найдите иконку **Button**
   - Или: `Toolbox → Components → Button`

2. **Кликните на экране**

3. **Настройте:**
   - **Object Name:** `b0`
   - **Size:** Width=100, Height=40
   - **Position:** X=190, Y=260
   - **Text:** `Settings`
   - **Font Color:** Белый
   - **Background Color:** Синий (0, 0, 255)
   - **Touch Event:** Включить (для обработки в коде)

## ⚠️ Частые проблемы

### Проблема: Проект пустой

**Решение:**
- Убедитесь, что выбрали правильную модель дисплея
- Добавьте компоненты вручную (см. выше)

### Проблема: Компоненты не видны

**Решение:**
- Проверьте позицию компонентов (не за пределами экрана?)
- Проверьте цвета (фон и текст одного цвета?)
- Увеличьте размер компонентов

### Проблема: Ошибки при компиляции

**Решение:**
- Проверьте имена компонентов (должны быть уникальными)
- Проверьте, что компоненты не выходят за границы экрана
- Попробуйте: `File → Build → Clean`, затем снова `Compile`
