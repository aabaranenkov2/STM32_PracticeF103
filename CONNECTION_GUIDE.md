# Руководство по подключению Nextion + DS3231

## 🔌 Подключение к STM32F103C8T6 (Blue Pill)

### Схема подключения:

```
┌─────────────────────────────────────────────────┐
│         STM32F103C8T6 (Blue Pill)               │
│                                                  │
│  PA2 (USART2_TX) ────────────> Nextion RX      │
│  PA3 (USART2_RX) <──────────── Nextion TX       │
│  5V              ────────────> Nextion VCC      │
│  GND             ────────────> Nextion GND      │
│                                                  │
│  PB6 (I2C1_SCL) ────────────> DS3231 SCL        │
│  PB7 (I2C1_SDA) ────────────> DS3231 SDA        │
│  3.3V            ────────────> DS3231 VCC        │
│  GND             ────────────> DS3231 GND        │
└─────────────────────────────────────────────────┘
```

## 📋 Детальное подключение

### Nextion NX4832T035_011:

| Nextion | STM32F103C8T6 | Примечание |
|---------|---------------|------------|
| VCC     | 5V            | ⚠️ Нужен преобразователь уровней для TX/RX |
| GND     | GND           | Общий минус |
| RX      | PA2 (USART2_TX) | ⚠️ Через преобразователь 3.3V→5V |
| TX      | PA3 (USART2_RX) | ⚠️ Через преобразователь 5V→3.3V |

**⚠️ ВАЖНО:** Nextion работает на 5V, STM32F103 на 3.3V!

**Решение для уровней:**
- Используйте резисторный делитель для TX (STM32→Nextion)
- Используйте простой делитель или модуль уровня для RX (Nextion→STM32)

### DS3231SN:

| DS3231 | STM32F103C8T6 | Примечание |
|--------|---------------|------------|
| VCC    | 3.3V          | Питание |
| GND    | GND           | Общий минус |
| SDA    | PB7 (I2C1_SDA) | I2C Data |
| SCL    | PB6 (I2C1_SCL) | I2C Clock |

**Примечание:** DS3231 работает на 3.3V, подключение напрямую безопасно.

## 🔧 Преобразование уровней для Nextion

### Вариант 1: Резисторный делитель (простой)

Для TX (STM32 → Nextion):
```
STM32 PA2 (3.3V) ──[1.8kΩ]──┬── Nextion RX
                            │
                          [3.3kΩ]
                            │
                           GND
```

Для RX (Nextion → STM32):
```
Nextion TX (5V) ──[2.2kΩ]──┬── STM32 PA3 (3.3V max)
                           │
                         [3.3kΩ]
                           │
                          GND
```

### Вариант 2: Модуль уровня (рекомендуется)

Используйте готовый модуль уровня (например, на основе TXB0104 или простой на транзисторах).

## ✅ Проверка подключения

### 1. Проверка DS3231 (I2C):

```bash
# Используйте i2cdetect (если есть I2C адаптер)
i2cdetect -y 1
# Должен показать устройство на адресе 0x68
```

Или в коде:
- LED должен мигать при ошибке инициализации DS3231

### 2. Проверка Nextion:

- При включении дисплей должен показать заставку
- После загрузки .tft файла должен показать интерфейс
- Если не работает - проверьте уровни напряжения

## 🔍 Отладка

### Проблема: Nextion не отвечает

1. Проверьте подключение TX/RX (не перепутаны?)
2. Проверьте уровни напряжения (3.3V ↔ 5V)
3. Проверьте скорость UART (9600 бод)
4. Попробуйте сброс: `Nextion_Reset()`

### Проблема: DS3231 не отвечает

1. Проверьте подключение I2C (SDA, SCL)
2. Проверьте подтягивающие резисторы (4.7kΩ на SDA и SCL)
3. Проверьте питание (3.3V)
4. Проверьте адрес (0x68)
