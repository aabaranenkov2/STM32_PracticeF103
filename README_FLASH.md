# ИНСТРУКЦИЯ ПО ПРОШИВКЕ STM32F103C8T6

## 🔧 Проблема: Контроллер не прошивается

Если перебрали несколько плат и результат не меняется, проблема может быть в:
1. **ST-Link прошивке** (старая версия)
2. **Защите контроллера** (readout protection)
3. **Неправильном подключении** (BOOT0, провода)
4. **Конфигурации OpenOCD**

## 🔍 ДИАГНОСТИКА ПРОБЛЕМ

### Проблема 1: "ST-Link не найден"
**Решение:**
```bash
# Проверить USB
lsusb | grep -i stm

# Если не найден:
# 1. Проверьте кабель USB
# 2. Попробуйте другой USB порт
# 3. Проверьте драйверы: lsmod | grep stlink
```

### Проблема 2: "Failed to enter SWD mode"
**Решение:**
1. **Проверьте BOOT0** - должен быть на GND (0)
2. **Проверьте провода:**
   - SWDIO → SWDIO
   - SWCLK → SWCLK
   - GND → GND
   - 3.3V → 3.3V (если нужно)
3. **Попробуйте нажать RESET** во время подключения

### Проблема 3: "Chip is locked"
**Решение:**
```bash
./unlock_chip.sh
```

### Проблема 4: "Programming failed"
**Решение:**
1. Попробуйте другой метод прошивки (st-flash вместо OpenOCD)
2. Выполните mass erase перед прошивкой
3. Проверьте размер прошивки (не должен превышать 64 KB для STM32F103C8T6)

## 🛠️ АЛЬТЕРНАТИВНЫЕ МЕТОДЫ

### Метод A: Обновление ST-Link прошивки
Если ST-Link старый, может не работать с новыми версиями OpenOCD:
```bash
# Проверить версию ST-Link
st-info --version

# Если версия старая, может потребоваться обновление
# (требует специального ПО от STMicroelectronics)
```

### Метод B: Использование другого ST-Link
Если есть другой ST-Link (например, от NUCLEO), попробуйте его.

### Метод C: Проверка через Serial (UART)
Если прошивка не работает, можно проверить через Serial:
```bash
# Подключите UART (PA9/PA10) к USB-UART адаптеру
# И проверьте вывод через minicom/screen
minicom -D /dev/ttyUSB0 -b 115200
```

### Метод D: Минимальный код без HAL
Если HAL не работает, используйте `src/main_simple.c`:
```bash
# Переименуйте файлы
mv src/main.c src/main_hal.c
mv src/main_simple.c src/main.c

# Скомпилируйте и прошейте
pio run
./flash_stflash.sh
```

## 📝 ПРОВЕРКА РАБОТЫ

После прошивки:
1. **LED должен мигать** - 1 секунда ВКЛ, 1 секунда ВЫКЛ
2. **Если не мигает:**
   - Нажмите RESET на плате
   - Проверьте, что LED подключен к PC13
   - Проверьте полярность (на Blue Pill LED активен LOW)

## 📞 ЕСЛИ НИЧЕГО НЕ ПОМОГАЕТ

1. **Проверьте физическое подключение:**
   - Все провода надежно подключены?
   - Нет коротких замыканий?
   - Правильная полярность?

2. **Попробуйте другую плату:**
   - Возможно, плата повреждена
   - Проверьте питание (3.3V стабильно?)

3. **Проверьте ST-Link:**
   - Работает ли с другими платами?
   - Попробуйте другой ST-Link

4. **Логи:**
   - Сохраните вывод всех команд
   - Проверьте `/tmp/unlock.log` и `/tmp/pio_flash.log`
