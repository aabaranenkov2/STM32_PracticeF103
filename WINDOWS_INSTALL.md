# Установка лотового датчика в Windows

## Требования

- Windows 10 или Windows 11, 64-битная версия.
- Подключённый к компьютеру USB–RS485 преобразователь.
- Для преобразователя CH340 Windows обычно устанавливает драйвер автоматически.
  Если COM-порт не появился в диспетчере устройств, установите драйвер CH340
  производителя преобразователя.

Python, PlatformIO и Cursor для работы программы не нужны.

## Установка

1. Скопируйте на компьютер файл `LotSensorSetup-v1.0.7.exe`.
2. Запустите его двойным щелчком.
3. Если Windows SmartScreen покажет предупреждение, нажмите
   «Подробнее» → «Выполнить в любом случае». Установщик пока не имеет
   коммерческой цифровой подписи.
4. Пройдите короткий мастер установки.
5. Оставьте установленным флажок «Запустить Лотовый датчик».

На рабочем столе и в меню «Пуск» появится ярлык «Лотовый датчик».

## Работа

1. Подключите контроллер через USB–RS485.
2. Запустите ярлык «Лотовый датчик».
3. Программа автоматически найдёт CH340. Если в системе только один COM-порт,
   будет выбран этот порт.
4. В браузере автоматически откроется страница:
   `http://127.0.0.1:8765/`.

Закрытие вкладки браузера не останавливает связь и периодические измерения.
Чтобы снова открыть страницу, ещё раз запустите ярлык.

## Отчёты

Отчёты сохраняются отдельно от установленной программы:

`Документы\Лотовый датчик\отчеты`

Каждый день создаётся новый файл с датой в имени. Удаление или обновление
программы не удаляет отчёты.

## Если контроллер не найден

1. Откройте «Диспетчер устройств» → «Порты (COM и LPT)».
2. Убедитесь, что USB–RS485 отображается без жёлтого знака ошибки.
3. Отключите другие лишние USB–COM преобразователи.
4. Переподключите USB–RS485 и снова запустите ярлык.
5. Проверьте, что другая программа не заняла COM-порт.

## Удаление

Откройте «Параметры» → «Приложения» → «Установленные приложения»,
выберите «Лотовый датчик» и нажмите «Удалить».

Папка отчётов в «Документах» при удалении сохраняется.

## Выпуск новой версии

Номер версии хранится в файле `VERSION`. Перед новой сборкой измените его,
например с `1.0.0` на `1.0.1`, и запустите:

```bash
packaging/windows/build_installer.sh
```

Имя нового установщика и версия на странице изменятся автоматически.
