# LotSensor 1.0.7

Выпуск добавляет информационную диагностику двигателя и механики:

- время полного цикла, парковки, спуска и подъёма;
- скорости вниз и вверх;
- средние показатели по последним 20 исправным замерам;
- состояния «накопление», «норма», «предупреждение» и «критично»;
- отдельный CSV в `отчеты/диагностика`.

Диагностика не останавливает механизм и не изменяет алгоритм измерения.

Файлы:

- `LotSensor-f103c8-v1.0.7.bin` — прошивка STM32;
- `LotSensor-f103c8-v1.0.7.bin.sha256` — контрольная сумма;
- `LotSensorSetup-v1.0.7.exe.sha256` — контрольная сумма установщика.

Копирование на флешку:

```bash
FLASH="/media/alex60/ИМЯ_ФЛЕШКИ"
cp -v dist/LotSensorSetup-v1.0.7.exe "$FLASH/"
cp -v releases/v1.0.7/* "$FLASH/"
sync
```
