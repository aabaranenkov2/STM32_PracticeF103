# Как правильно открыть проект STM32_PracticeF103

## Проблема: Открывается Welcome to PlatformIO вместо вашего проекта

Если при запуске Cursor открывается экран "Welcome to PlatformIO" и вы не видите свои файлы, значит открыт не тот проект.

## Решение: Откройте Workspace файл

### Способ 1: Через скрипт (самый простой)

```bash
cd /media/alex60/INFO/Project-Bots/bots/Fitnes/ProjectsRST32/STM32_PracticeF103
./open_project.sh
```

### Способ 2: Вручную через меню Cursor

1. **Закройте текущее окно** (File → Close Window или Ctrl+Shift+W)
2. **Откройте Workspace файл:**
   - File → Open Workspace from File...
   - Или нажмите `Ctrl+K Ctrl+O`
   - Выберите файл: `/media/alex60/INFO/Project-Bots/bots/Fitnes/ProjectsRST32/STM32_PracticeF103/STM32_PracticeF103.code-workspace`

### Способ 3: Через командную строку

```bash
cursor /media/alex60/INFO/Project-Bots/bots/Fitnes/ProjectsRST32/STM32_PracticeF103/STM32_PracticeF103.code-workspace
```

## Что вы должны увидеть после правильного открытия:

✅ В левой панели (Explorer) должны быть видны:
- Папка `src/` с файлами main.c и другими
- Папка `include/` с заголовочными файлами
- Файл `platformio.ini`
- Все ваши скрипты (.sh файлы)
- Документация (.md файлы)

✅ В нижней панели должна быть кнопка PlatformIO (иконка с домиком)

✅ В левой панели должна быть иконка PlatformIO (если расширение установлено)

## Если расширения не видны:

1. Нажмите `Ctrl+Shift+X` чтобы открыть панель расширений
2. Проверьте, что установлены:
   - **C/C++** (ms-vscode.cpptools)
   - **PlatformIO IDE** (platformio.platformio-ide)

## Если ничего не помогает:

1. Закройте все окна Cursor
2. Откройте терминал
3. Выполните:
   ```bash
   cd /media/alex60/INFO/Project-Bots/bots/Fitnes/ProjectsRST32/STM32_PracticeF103
   cursor STM32_PracticeF103.code-workspace
   ```

## Важно:

- **Всегда открывайте файл `.code-workspace`**, а не просто папку проекта
- Workspace файл содержит настройки проекта, пути к файлам и конфигурацию терминала
- Если открыть просто папку, многие настройки не применятся
